# 地震道集标注器（Seismic Understanding Biaozhu）

地震道集（炮集 / CMP 道集 / 共检波点道集 / 残差等）特征标注工具，
产出「道集 ↔ 标签 ↔ 自然语言句子 ↔ 图片 ↔ 区域框」数据集，
供分类、多模态与目标检测模型训练。

**特性**

- 自实现 SEG-Y 读取层：大端/**小端**自动检测、1-based 任意字节道头、numpy memmap（大文件友好）
- Web 标注界面（Gradio）：浏览器即用，支持断点续标、多文件合并标注
- 5 项特征标签体系，配置驱动（改 `label_config.yaml` 即可增删特征，无需改代码）
- **键盘一路答完选择题**：当前题高亮显示，按数字键 `1`～`9` 选中对应选项后**自动跳到下一题**，
  `↑`/`↓` 可前后移动当前题；标注时基本不用鼠标点选项
- 面波 / 近炮点强能量噪声用 **`Ctrl`+左键点两角**框选（检测训练用，像素 + 原始数据双坐标），
  成框后仍可拖动/拖角缩放微调
- 面波区**按需带通滤波**：设 f1～f4 四角频率后一键应用（SeiSee 同款算法），**只影响看，
  不影响导出图与标签**；滤波前后**共用同一色标**，压掉多少能量一眼可比
- 建作业支持**道数下限**与**抽稀间隔**：先滤去道数过少的道集，再按抽取顺序等间隔删
- clip 随机采样数据增强：保存一张道集即自动产出 **5 张不同随机 clip** 的训练图
  （clip 上下限在建作业时设置）
- 每条记录自动渲染自然语言句子（句子模板可配置）

### 部署与启动

```bash

```

- 也可双击项目根目录 `启动.bat`。
- 服务机为安装本项目的这台 Windows 机器；首次启动若 `users.yaml` 不存在会自动写入

### 账号与角色（users.yaml，热生效）

- 账号表在项目根目录 `users.yaml`，两种角色：
  - `admin`（例：boss）—— 建作业、作业管理（打开/关闭、全部重传、删除/恢复）、账号增删（改文件）
  - `annotator`（例：ann1）—— 只能从任务池领取、标注、保存，查看/修改自己标过的记录
- **「③ 标注量 / 作业进度」区对两种角色都可见**：每 5 秒自动刷新，列出各作业的
  已完成 / 总数与进度条，任何人在标注时都能看到整体推进情况（管理操作仍在「④ 管理」，
  仅 admin 可见）。表内不含标注者姓名，只有作业级的汇总计数。
- **个人标注总量**：标注区常驻一行「我的累计标注：N 张」（**跨全部作业**，随每次保存刷新）；
  管理员的「④ 管理」区另有一张**各用户标注总量表**（列出 `users.yaml` 里全部账号，
  含 0 张的，并给出合计）。统计口径：只数实际标注的**道集张数**——他人覆盖重标同一张时
  仍归原标注者，软删除的作业不计入（与进度表口径一致），每次保存附带的 5 张增强图不重复计数。
- 每次登录都会重新读 `users.yaml`：**改文件即生效，无需重启服务**（已登录会话不受影响）。
- 默认账号：`boss / boss123`（admin）、`ann1 / ann123`（annotator）。

### 建作业（admin）

- admin 登录后在「① 建作业」填 sgy 路径、排序键、抽道集键，勾选要抽的键值，
  再设三个 clip 参数后「创建作业」：
  - **预览 clip 分位数**（默认 99，仅界面显示/画框参照用）；
  - **增强 clip 下限 / 上限**（默认 90 / 99.9）——每次保存时从该范围随机采
    **5 个互不相同的 clip 值**，各渲一张增强导出图（范围须宽到能采满 5 个，0.1 步长）；
  - **道数下限**（默认 20，0=不限）：道数少于该值的道集从作业池滤去、不标注；
  - **抽稀间隔 N**（默认 1，0/1=不抽稀）：按抽取顺序**每 N 个道集保留 1 个**进任务池
    （N=2 即留第 1、3、5… 个，去掉一半），用于按比例缩小作业规模。
    执行顺序是**先按道数下限过滤、再抽稀**——劣质道集先出局，抽稀只削好道集。
    两个参数都写进 `job.json`，重启恢复时原样施加，任务池不会变。
- 服务端抽一次道集即生成一个作业，落在 `jobs/<job_id>/`；标注者之后从该作业的
  任务池按顺序领一张标一张。

> ⚠️ **旧版作业（v3.5 及以前建、job.json 无增强上下限）不兼容**：重启后会被标为
> 「异常」，无法领取/保存，需在管理④区删除后按新参数重建。

### 任务池领取语义（标注）

- 作业 = 一批待标道集（有序任务池）。标注者在「② 作业与标注」**选中作业即自动领取第一张**
  （不用再点按钮）；「领取下一张」按钮保留，用于归还/跳过之后手动继续。
- **可同时选多个作业组成作业池**：把选中作业里所有可领道集**摊平后等概率**随机抽一张
  —— 等价于按各作业的道集数量比例抽（900 张的作业与 100 张的作业，抽中概率约 9:1）。
  保存/跳过后继续从池里抽，所以两个作业会交替着标；当前这张属于哪个作业会显示在顶部，
  进度也分开报（`本作业 12/900 ｜ 作业池 134/1000（共 2 个作业）`）。
  近期「跳过」过的道集会被优先避开，只在池里没别的可领时才回来（防止反复抽到同一张）。
- 领取即加**租约**（默认 TTL 30 分钟，交互自动续期）：每张同一时刻只被一人持有；
  关浏览器/挂机超时自动回收回池，不卡死任务；「归还此张」主动放回（不写记录）。
- 保存成功即标记已标、释放租约，进度（labeled/total）实时刷新。
- 只能重开「我标注的」里自己的历史记录修改；他人的记录与进行中道集不可见不可写。

### 结果落点

```
jobs/<job_id>/
├── job.json         # 作业元数据（含 clip_percentile 预览、aug_lo/aug_hi 增强范围等）
├── labels.jsonl     # 标注记录：每张道集 1 条基础记录 + 5 条增强记录
├── images/          # 导出增强图 images/<gid>__clip<值>.png（纯数据图，512×1024）
└── npy/             # 原始数据 float32（留本地，不上云）
```

- 保存一张道集：基础记录（`gather_id=<gid>`，`image_path: null`，用于断点/进度/重开）
  + **5 条增强记录**（`gather_id=<gid>__clip<值>`、`augmented_from=<gid>`、`clip_percentile`=值），
  每条 labels/sentence/regions 与基础一致（区域坐标按道/采样换算，天然与 clip 无关）；
  图片与记录一一对应，无孤立图。重复保存同一道集自动清理旧增强后再采样，不会堆积。

### 开启 COS 云回传（可选）

- 编辑项目根目录 `cos_config.yaml`：`enabled: true` 并填 `secret_id / secret_key /
  bucket / region`（密钥只存本机，永不进代码/日志），保存后**重启服务**生效。
- 依赖：`pip install cos-python-sdk-v5`；未启用或未装依赖时安全降级为本地模式，不阻塞标注。
- 保存成功后异步上传本次落盘的 **5 张增强图**（v3.14 起等后台画完才传，见下方「数据增强」）+ 整份 `labels.jsonl`，对象键为
  `seismic/<job_id>/images/<gid>__clip<值>.png`、`seismic/<job_id>/labels.jsonl`；
  失败自动有界重试并写 `jobs/<job_id>/upload.log`，admin 可「全部重传」重推
  （重传按目录扫 `images/*.png` 全量上）。
- `npy`（原始数据）按设计**只留本地，不上云**。

### 数据增强：内置（保存即做）+ 离线脚本（可选）

- **v3.6 起增强内置回标注循环**：保存一张道集自动按作业的增强 clip 范围随机采
  5 个值、渲染 5 张增强图并各写一条 `augmented_from` 记录（即上方「结果落点」语义），
  无需再额外跑脚本。
- **v3.14 起这 5 张图由后台线程画**（记录仍同步落盘）：它们是给训练导出/云回传用的，
  与「下一张标什么」无关，却曾占掉点「保存并释放」后等待的 82%（实测 528 道 × 4000
  采样下 0.64s / 0.78s）。现在点完立刻能进下一张，提示语会写「增强图（后台生成中）」。
  - 副作用：**保存刚返回的那一瞬间，`images/` 里可能还没有这几张图**，通常几百毫秒后
    补齐。要「返回时图就在」（离线脚本、测试）可用 `save(..., aug_sync=True)`。
  - 进程若在画图途中被杀（窗口约每次保存 0.1~0.5s），启动时会自动扫描并补画缺的图；
    离线仍可跑下方的 `backfill_augment.py`。
- 若历史数据是单图基础记录、想补成 clip 采样增强，仍可离线跑 `backfill_augment.py`：

```bash
python backfill_augment.py jobs/<job_id>/labels.jsonl    # 默认每条 5 张，可加张数参数
```

- 若已开启 COS，增强完成后可在管理页对该作业「全部重传」一并回传。

## 使用流程

### 第 1 步：文件与道集设置

- 填 sgy/segy 文件路径（支持大端/小端，默认自动检测）→「读取文件信息」
- 填排序键：如 `95-96, 13-16`（1-based 字节号，先按前者再按后者，升序）
- 填抽道集键：如 `95-96` → 点「扫描键值」→ 勾选要抽的值（默认全选）
- 选输出目录 →「生成道集」

### 第 2 步：预处理设置

- clip 分位数（默认 99%），可预览第一个道集效果
- **可选数据增强**：填增强 clip 下限/上限和张数 N（N=0 不增强）→「开始标注」

> **增强说明**（N>0 时）：保存时在 [下限,上限] 内随机采 N 个互不相同的 clip 值，
> 各渲染一张增强图（`images/<gather_id>__clip<值>.png`），每张在 labels.jsonl 中是
> 一条独立记录（labels/sentence/regions 与基础记录相同，另含 `augmented_from`、
> `clip_percentile` 字段）；基础记录保留但 image_path 为 null；npy 原始数据只存一份；
> 重复保存同一道集会自动清理其旧增强记录与图片再重新采样。

### 第 3 步：标注

**选中作业（可多选）会自动从作业池领到第一张**，右侧立刻显示该道集与 7 个题项
（不必点「领取下一张」）。取消勾选当前道集所属的作业会让当前道集作废并等待重新抽取。
左侧当前道集图，底部按钮：领取下一张 / 跳过此张 / 归还此张 / 刷新 / 继承最近已标注 /
保存并释放 / ↩ 返回上一张。**推荐流程：先键盘答完选择题，再用鼠标框选，最后 Enter 保存**。

题目顺序固定为 7 项：**1 集合类型 → 2 异常振幅 → 3 混叠噪声 → 4 面波 → 5 近炮点强能量噪声
→ 6 面波拉框 → 7 近炮点强能量拉框**（前 5 项是选择题，后 2 项是框选）。顺序由
`label_config.yaml` 的标签顺序决定（带框特征放最后）。

**① 键盘答选择题（1～5）** —— 当前题有**蓝色高亮框**（整块标题+选项发光），一眼看得到在答哪道。
- 焦点不在输入框时，按数字键 `1`～`9` 即选中**当前题**的对应选项（选项名前的数字就是键位），
  选完**自动跳到下一题**并高亮，一路按下去即可答完。
- `↑` 到上一题、`↓` 到下一题（可回去改答案；改完按数字键会覆盖原选择）。
  方向键走的是**题**，不会在同一题的选项之间跳（`←`/`→` 也一并屏蔽，避免浏览器
  默认的「同组内换选项」行为抢走按键）。
- 到拉框项（6/7）时数字键不再动作。在文本框里打字不影响（数字键照常输入）。
- **选了「不存在」的那一步自动跳过**：面波选「不存在」，第 6 步「面波拉框」会被直接跳过
  （该步置灰、状态行写「无需画框（本步自动跳过）」），近炮点强能量同理。改回「存在」即恢复。
- 全部答完（含跳过的框选步骤）后按 **`Enter`** 即「保存并释放」并自动领取下一张，
  全程不用碰鼠标。焦点在输入框里时 `Enter` 不触发保存。

**② 鼠标框选（6、7）** —— 对应的选择题选了「不存在」时，这一步会被自动跳过（见上）。
- 在图上按住 **`Ctrl`**（Mac 为 `Cmd`）点**两个对角**即确定矩形；点下第一角后有十字标记
  与虚线预览提示。**矩形确定后仍可用普通左键拖动、拖角缩放微调**，松手即保存到服务端。
- 也可以 **`Ctrl`+左键点下第一角 → 移动鼠标 → 松开 `Ctrl`** 直接成框（第二角取松开瞬间的
  鼠标位置，虚线预览一直在跟着走）。两条路等价，按顺手来。松手时若鼠标没动、框太小，
  则不成框且**第一角保留**，仍可照旧 `Ctrl` 再点第二角。
- **点右键即清除此框**：有点下第一角还没闭合的半成品时，右键丢弃它；否则鼠标压在
  **已经落定的框**上就删掉那个框（等同该特征的「✕ 清除此框」，本地立即消失、服务端同步清掉）。
  空白处右键不做任何事。
- 画给哪个特征由服务端按「**第一个需要框但还没框**」自动判定，画布左上角会显示当前目标；
  两个特征都框好后，再 `Ctrl` 点击即重画最后一个。选了「不存在」的题会自动跳过（不需框）。
- 「✕ 清除此框」**点一下就清掉**（本地立即消失）。显示图上叠加的框仅供查看，
  **导出的训练图保持干净**。
- 标签为「存在 / 已压制但有残留」时**必须画框才能保存**；「不存在」时框自动置空。

**③ 按需滤波**（面波区的「⚙ 滤波」按钮）—— 面波常把整个剖面压饱和，看不清底下还有什么。
- 填好四角频率后**点一次按钮即应用**，当前显示图换成滤波后数据；**再点一次还原**。
- `f1` 低截 / `f2` 低通拐点 / `f3` 高通拐点 / `f4` 高截（单位 Hz，须满足
  `0 ≤ f1 < f2 < f3 < f4`），过渡带按余弦渐变；初始值 8 / 9 / 120 / 121。
- 算法与 `bandpass.py` 同一套（SeiSee 逐道零相位 FFT 带通），采样间隔取自建作业时的道头。
- **参数按作业记忆**：一个作业里第一次设好参数后，该作业后续每次点按钮都用这套参数，
  输入框也会回填成它，不用重填；但**每张必须重新点一次才应用**（不会默认生效），
  避免忘了关掉而按滤波图下标注。
- **滤波前后共用同一色标**（色标界限只从原始数据算一次）：被滤掉的能量会真的显示为变淡，
  两张图可直接对比，不会被重新拉伸成一样的对比度。
- **滤波只改变「显示图」**：导出的训练图与 npy 始终是原始数据，标签语义完全不受影响。
- 想滤掉面波看剩余有效信号，就把 `f1/f2` 设到面波频带之上（如 30/40/80/100）。

其余：
- 「继承最近已标注」：回找最近一张**已保存**的道集复制其类别选项
  （自动跳过中间未标注的道集；框不继承，需另行框选）
- **「↩ 返回上一张」**：退回上一个**访问过**的道集（按浏览历史回退，不是按标注顺序），
  连点可一路往回翻，到最早一张会明确提示。改完点「保存并释放」即**覆盖原结果**。
  手上那张是刚领来**还没作答**的（保存后自动领到的那种）→ 自动归还回池再往回走；
  已经作答过的才拦下来问一句，避免把真实工作静默丢掉。
- 「保存并释放」**一律**存完自动领下一张 —— 包括返回上一张做的**修正**保存（只是提示语会
  写明是「已覆盖原结果」，方便区分新增与修改；保存前后那张也会进浏览历史，还能点回去）。
- 全部特征选完才能保存；保存时自动导出 PNG 与 npy
- 重开程序自动从未标注的道集继续（断点续标）；已标注的可返回修改

## 输出与数据格式

```
输出目录/
├── labels.jsonl          # 每张道集 = 1 基础行 + 5 增强行
├── images/<文件名前缀>__<键>_<值>__clip<值>.png   # 增强导出图（每张道集 5 张），纯数据图 512×1024 RGB
└── npy/<文件名前缀>__<键>_<值>.npy                # 原始数据：float32 (道数,采样点数)，无预处理，供重渲染各 clip
```

JSONL 单条示例：

```json
{
  "gather_id": "01SB21_DenoiseB4_FFID19037__95-96_1373",
  "gather_key": "95-96",
  "gather_value": 1373,
  "n_traces": 528,
  "labels": {"gather_type": "炮集", "surface_wave": "已压制但有残留", "abnormal_amplitude": "不存在", "near_shot_noise": "不存在", "aliasing_noise": "不存在"},
  "sentence": "这是一条炮集，面波已压制但有残留，异常振幅不存在，……。",
  "regions": {"surface_wave": {"xyxy": [100, 200, 300, 600], "traces": [103, 311], "samples": [781, 2348]},
              "near_shot_noise": null},
  "image_path": "images/01SB21_DenoiseB4_FFID19037__95-96_1373.png",
  "npy_path": "npy/01SB21_DenoiseB4_FFID19037__95-96_1373.npy",
  "sort_keys": "95-96, 13-16",
  "extract_key": "95-96",
  "source_file": "/path/to/xxx.sgy",
  "timestamp": "2026-08-21T00:40:00"
}
```

> **v3.6 起多用户版的真实落点**：基础行 `image_path` 为 `null`；同时写 **5 条增强行**——
> 在基础行字段之上把 `gather_id` 换成 `<gid>__clip<值>` 并追加
> `"augmented_from": "<gid>"`、`"clip_percentile": <值>`、`"image_path"` 指向对应 clip 图
> （`images/<gid>__clip<值>.png`）。上面示例为旧版单图记录形态，仅作字段结构参考。

**`regions` 字段**（仅 `label_config.yaml` 中 `bbox: true` 的特征有）：同一块区域的两套坐标——

| 字段 | 含义 | 用法 |
|---|---|---|
| `xyxy` | 512×1024 导出图上的像素坐标 `[左上x, 左上y, 右下x, 右下y]` | 检测模型训练直接用 |
| `traces` / `samples` | 原始数据的道/采样点下标范围，半开区间 `[起, 止)` | npy 切片：`data[t0:t1, s0:s1]` |

> **多文件合并**：gather_id 与图片名均带来源文件名前缀（如
> `01SB21_DenoiseB4_FFID19037__95-96_1373`），因此可以把多个 sgy 文件
> 标注到同一个输出目录，记录自动合并、互不覆盖；同一文件跨会话标注自动续标。

## 自定义标签体系

编辑 `label_config.yaml` 即可，**无需改代码**：

- 增删特征、选项、数字快捷键、选项拼句子措辞（`phrase`）、句子模板
- 某特征需要框选：加 `bbox: true`（可选 `bbox_color: "#rrggbb"`）
- **特征顺序即界面与键盘答题顺序**（自上而下单列）。带框特征（`bbox: true`）必须放在
  **最后**并保持连续：界面据此把它们渲染成独立的「拉框项」排在所有选择题之后
  （当前配置排成 1 集合类型 / 2 异常振幅 / 3 混叠噪声 / 4 面波 / 5 近炮点强能量噪声
  / 6 面波拉框 / 7 近炮点强能量拉框）
- 删特征不影响已产出的 `labels.jsonl`：旧记录里残留的字段不参与校验，可照常读取；
  要让旧记录也按新体系重写，跑 `migrate_remove_features.py`
- 面波区的「⚙ 滤波」按钮挂在 `key: surface_wave` 上；改该 key 时同步改
  `web_app.py` 的 `FILTER_FEAT_KEY`（该特征被删掉时滤波按钮自动不出）

## 模块结构

| 文件 | 职责 |
|---|---|
| `segy_reader.py` | SEG-Y 读取（端序自动检测、1-based 任意字节道头、memmap） |
| `gather.py` | 多道头排序、按键抽道集 |
| `preprocess.py` | 预处理管线（注册表模式，可扩展）、clip 无放回采样、SeiSee 带通滤波步骤 |
| `bandpass.py` | SeiSee 四角频率带通算法（独立 SEG-Y 滤波脚本；`preprocess.py` 复用其算法） |
| `imaging.py` | 道集 → seismic 配色图；纯数据图渲染；框叠加显示 |
| `labels.py` / `label_config.yaml` | 标签体系与句子渲染 |
| `storage.py` | JSONL 存储与断点续标 |
| `jobmanager.py` | 作业池（建作业/道数下限/抽稀/租约/保存导出）、显示图与滤波缓存 |
| `web_app.py` | Gradio Web 界面（主用） |
| `main_window.py` | PyQt5 向导式界面（备用） |
| `backfill_npy.py` / `backfill_augment.py` / `migrate_remove_features.py` | 历史数据回补/迁移脚本 |

## 注意事项

- 道头字节号为 **1-based**（SEG-Y 标准文档惯例），区间长度须为 1/2/4/8 字节
- 小端 SEG-Y 非标准但常见，本工具自实现读取层支持
- `fonts/NotoSansCJKsc-Regular.otf` 为出图中文字体，勿删
- 计划与版本迭代记录见 `PLAN.md`、`MEMORY.md`
